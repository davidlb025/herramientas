Cómo funciona y formatos compatibles

1. Abre este HTML en Chrome o Edge y elige un MP4, WebM o WebP. 2. Sube una narración (MP3, WAV, M4A, OGG u otro audio compatible) o grábala con el micrófono. 3. Ajusta la voz, el sonido del vídeo, la duración y el encuadre. Reproduce para comprobar la mezcla. 4. Exporta y descarga el resultado.

Todo se procesa en tu navegador, sin subir archivos a ningún servidor. Los formatos de vídeo disponibles se detectan en tu navegador: MP4 cuando admite su grabación; WebM como alternativa. WAV exporta solo la mezcla de audio. Un WebP con sonido se guarda como vídeo, ya que WebP no contiene audio. Los WebP animados necesitan la API ImageDecoder; si no está disponible se mostrará un aviso.

La grabación requiere permiso de micrófono. Si tu navegador lo bloquea al abrir un archivo local, usa Chrome o Edge, o sube un audio ya grabado. Las exportaciones largas o 4K consumen memoria; reduce la resolución si es necesario. No se guarda el proyecto al cerrar. Los archivos ya descargados se conservan.
