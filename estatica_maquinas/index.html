Longitudes base

Define una medida (por ejemplo L1 = 1 m). Las barras con esa referencia miden siempre lo mismo.

Cables

Marca una barra como cable para calcular su diámetro. Indica σadm, o bien fy y el coeficiente de seguridad n (σadm = fy / n).

Pulsa «Calcular» para obtener reacciones, esfuerzos en barras y los sólidos libres.

Diagramas de sólido libre

Cada nudo y cada barra se aísla con las fuerzas que actúan sobre él. Las flechas parten del punto donde se aplica la fuerza. Azul: tracción. Rojo: compresión. Naranja: cargas. Verde: reacciones.
